# GAMES-NATHAN

Пиксельный браузерный beat ’em up с Натаном. Три уровня: город, лес и завод; три волны на каждом уровне и финальный босс. Интерфейс и игровые надписи на русском, английском и иврите.

## Запуск

Требуется Node.js 20 или новее. Внешние npm-зависимости отсутствуют.

```sh
npm start
```

Откройте http://127.0.0.1:4173/. Для размещения на статическом хостинге используйте содержимое `dist/`. Запуск ES-модулей требует HTTP-сервера; открытие `index.html` через `file://` не поддерживается.

## Управление

| Клавиши | Действие |
| --- | --- |
| WASD / стрелки | Движение по арене |
| J | Удар рукой; удержание — серия |
| K | Удар ногой |
| E / L | Захват и бросок ближайшего противника |
| Q | Удар ярости при заполненной шкале |
| Пробел | Рывок с краткой неуязвимостью |
| C | Присесть; медленное движение и уклонение от обычных высоких ударов |
| 1–5 | Использовать предмет |
| Escape / P | Пауза |

Язык и рекорд сохраняются локально в браузере. При потере фокуса или переходе на другую вкладку игра автоматически ставится на паузу.

## Игра на телефоне

Для боя поверните телефон горизонтально. Игра занимает весь доступный экран; зоны управления расположены по краям, чтобы кнопки не закрывали Натана и основное поле боя. Крупные кнопки атак размещены дугой справа. Можно одновременно двигаться одним пальцем и атаковать другим.

При касании левой зоны появляется плавающий джойстик. Ведите палец от точки касания: движение поддерживает восемь направлений, а скорость зависит от отклонения. Небольшая область около центра нейтральна. Возврат к центру или отпускание пальца останавливает движение. Для смены атаки можно переводить второй палец между кнопками, не отрывая его от экрана.

| Кнопка на экране | Действие |
| --- | --- |
| □ | Удар рукой; удержание продолжает серию |
| △ | Захват и бросок ближайшего противника |
| ○ | Удар ногой |
| × | Рывок |
| L1 | Приседание при удержании |
| R1 | Удар ярости при заполненной шкале |

Пять предметов находятся в раскрывающейся сумке: откройте её кнопкой сумки и коснитесь нужного значка. После выбора сумка закрывается. Удержание L1 уменьшает скорость и позволяет пропускать над головой обычные высокие удары. От атак босса приседание не защищает. Управление с клавиатуры остаётся доступным.

При повороте в портретную ориентацию бой останавливается и появляется подсказка о повороте экрана. После возвращения в горизонтальную ориентацию начинается отсчёт 3–2–1, затем бой продолжается. Отсчёт можно отменить и остаться на паузе; повторный поворот прерывает текущий отсчёт. Кнопка в подсказке позволяет вернуться в меню. При паузе и смене ориентации удерживаемые команды сбрасываются.

Ручная пауза и уход приложения в фон требуют явного продолжения. Переход на другую вкладку, потеря фокуса или уход с экрана игры отменяют автоматическое возобновление, в том числе во время отсчёта.

При запуске боя на телефоне игра запрашивает полноэкранный режим и горизонтальную ориентацию, если браузер поддерживает эти возможности. Кнопка «На весь экран» позволяет повторить запрос. При отказе браузера арена продолжает занимать доступную область окна; выход из полноэкранного режима ставит текущий бой на паузу.

На iPhone для запуска без панелей Safari откройте страницу в Safari, выберите «Поделиться» → «На экран “Домой”» и затем запускайте игру значком NATHAN. Если показан переключатель «Открывать как веб-приложение», оставьте его включённым. Режим запуска зависит от браузера; manifest и метаданные задают полноэкранное отображение с резервным режимом standalone. [Документация WebKit о запуске с домашнего экрана](https://webkit.org/blog/17333/webkit-features-in-safari-26-0/#every-site-can-be-a-web-app-on-ios-and-ipados).

## Установка и игра без сети

На Android откройте игру в Chrome и выберите установку приложения в меню браузера. На iPhone используйте добавление на домашний экран, описанное выше. Манифест задаёт горизонтальную ориентацию, режим `standalone` и предпочтение полноэкранного запуска через `display_override`; браузер выбирает поддерживаемый режим. [Описание режимов запуска](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Manifest/Reference/display_override).

Для первого запуска нужен интернет. После успешной установки service worker сохраняет **все файлы игры**: три уровня, спрайты и метаданные, интерфейс, иконки и локальные шрифты. Затем игру можно заново открыть без сети. Для разработки service worker доступен на `localhost`; опубликованной игре требуется HTTPS. [Жизненный цикл и офлайн-кэш service worker](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API/Using_Service_Workers).

Кэш устанавливается целиком и проверяется по SHA-256. Если загрузка прервана или сервер вернул неверный файл, новая версия не активируется, а предыдущая остаётся доступной. Обновления ждут закрытия старых вкладок и окон игры: текущий бой не перезагружается. Чтобы перейти на уже загруженное обновление, закройте все окна NATHAN и откройте игру снова.

Перед публикацией **после последнего изменения любого файла в `dist/`** выполните:

```sh
node scripts/build-sw.mjs
node scripts/build-sw.mjs --check
npm test
```

Генератор записывает `dist/sw.js` с детерминированной версией и полным списком файлов; вручную редактировать его не нужно. Хост должен обслуживать содержимое `dist/` из корня сайта. `sw.js` должен возвращаться как JavaScript, а не попадать под HTML-перенаправление SPA. Файл `_headers` содержит настройки MIME и запрет HTTP-кэширования worker для совместимых статических хостингов. Сам service worker никогда не заменяет ответ `/sw.js` страницей `index.html`.

При регистрации используйте `navigator.serviceWorker.register('/sw.js', { scope: '/', updateViaCache: 'none' })`. Не вызывайте `skipWaiting()` и не перезагружайте страницу при `controllerchange`. Для проверки готовности к офлайн-режиму можно отправить активному worker сообщение `{ type: 'NATHAN_PWA_STATUS' }` через `MessageChannel`; ответ содержит `offlineReady` и номер версии.

| Виванс 30 / Vyvanse 30 / ויואנס 30 | +30 к силе на 120 секунд; заменяет более слабое усиление |
| Шмаль / Weed / גראס | Противники движутся в 0,42 от обычного темпа, урон Натана ×1,25; 120 секунд |
| Оземпик / Ozempic / אוזמפיק | Более стройный силуэт и скорость ×1,7; 120 секунд |

Это условные аркадные механики. Таймеры усилений идут только во время игры и замораживаются на паузе. Предметы выпадают из противников; между уровнями запас пополняется.

## Проверки

```sh
npm test
npm run check
```

Тесты проверяют урон и дальность ударов, уклонение, броски, ярость, усиления, подбор предметов, паузу и прохождение кампании. Отдельно проверяются направления и скорость джойстика, независимые указатели, переключение атак скольжением, короткие нажатия, очистка ввода и отмена отсчёта при поворотах или уходе в фон.

Приёмка на физическом iPhone в Safari и при запуске с домашнего экрана пока не проведена. Проверки размеров окна в настольном браузере и автоматические тесты не подтверждают поведение реальных касаний, системных жестов и панелей Safari.

## Структура

- `dist/game-core.js` — детерминированная боевая симуляция без DOM.
- `dist/renderer.js` — арена, персонажи, эффекты и анимация на Canvas.
- `dist/app.js` — управление, интерфейс, аудио и сохранение рекорда.
- `dist/touch-input.js` — направления, нейтральная зона и сила отклонения джойстика.
- `dist/touch-controls.js` — захват указателей, плавающий джойстик и независимые нажатия атак.
- `dist/mobile-shell.js` — размеры видимой области и отменяемый отсчёт возобновления.
- `dist/i18n.js` — локализация интерфейса.
- `dist/manifest.webmanifest`, `dist/apple-touch-icon.png` — запуск с домашнего экрана и иконка iOS.
- `dist/manifest.json` — идентичный манифест для основной ссылки установки.
- `dist/sw.js`, `scripts/build-sw.mjs` — проверяемый кэш полной версии игры и его генератор.
- `dist/assets/fonts/` — локальные WOFF2-шрифты с лицензиями OFL для работы без сети.
- `dist/assets/` — спрайты, метаданные кадров и промпты генерации.
- `tests/` — тесты Node.js.

`tests/pwa.test.mjs` проверяет реальный код worker в имитации Cache API: полную установку, откат при сбое, загрузку без сети, неизменность версии во время игры, восстановление проверенных файлов, MIME worker и очистку только собственных старых кэшей. Также проверяются размеры PNG-иконок и актуальность списка файлов перед выпуском.

Три попавших подряд удара рукой завершаются мощным хуком. Броски сбивают других противников по траектории; шкала ярости заряжается от боя и открывает круговой спецудар. Для усиления ощущения веса применяются короткая остановка при попадании, отбрасывание, вспышки контакта и многослойные звуковые эффекты. Режим уменьшенного движения снижает тряску и визуальные эффекты.

Спрайты созданы встроенным imagegen по утверждённому пиксельному варианту и фотографиям пользователя. Исходные фотографии в репозиторий не включены. Игра — первая играбельная версия, которую можно расширять новыми приёмами, уровнями и анимациями.
